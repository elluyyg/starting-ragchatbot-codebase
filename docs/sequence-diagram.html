RAG Query Flow Sequence Diagram

sequenceDiagram
    participant User
    participant Frontend
    participant FastAPI
    participant RAGSystem
    participant AIGenerator
    participant ToolManager
    participant CourseSearchTool
    participant VectorStore
    participant ChromaDB

    User->>Frontend: Types query, submits
    Frontend->>FastAPI: POST /api/query {query, session_id}
    FastAPI->>RAGSystem: rag_system.query(query, session_id)

    RAGSystem->>AIGenerator: generate_response(query, history, tools, tool_manager)

    AIGenerator->>AIGenerator: Build system prompt + history
    AIGenerator->>AIGenerator: POST to Claude with tools=[search_course_content]

    alt Claude decides to search
        AIGenerator->>ToolManager: execute_tool("search_course_content", query, ...)
        ToolManager->>CourseSearchTool: execute(query, course_name, lesson_number)
        CourseSearchTool->>VectorStore: search(query, course_name, lesson_number)
        VectorStore->>ChromaDB: Semantic similarity search
        ChromaDB-->>VectorStore: Return matching chunks
        VectorStore-->>CourseSearchTool: Return SearchResults
        CourseSearchTool-->>ToolManager: Formatted results + sources
        ToolManager-->>AIGenerator: Return tool result string
        AIGenerator-->>AIGenerator: Continue with Claude synthesis
    end

    AIGenerator-->>RAGSystem: Final response text
    RAGSystem-->>FastAPI: (answer, sources)
    FastAPI-->>Frontend: {answer, sources, session_id}
    Frontend->>User: Display answer + sources
